# DDD Invoices
 
> DDD Invoices is a unified API platform for e-invoicing, fiscalization, and real-time
> reporting compliance. Businesses use it to automate invoice compliance across multiple
> countries through a single integration — covering e-invoicing, fiscalization, PEPPOL,
> AI document processing, and embedded compliance APIs.
